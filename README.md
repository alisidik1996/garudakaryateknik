# 📘 Panduan & SOP Pengoperasian Website Resmi PT Garuda Karya Teknik

Selamat datang di dokumentasi resmi **Standard Operating Procedure (SOP)** dan panduan operasional pengelolaan website resmi **PT Garuda Karya Teknik** ([garudakaryateknik.com](https://garudakaryateknik.com)).

Dokumen ini disusun khusus untuk staf internal, tim marketing, dan administrator dalam mempublikasikan pembaruan proyek (*Selected Works*), artikel berita teknik, mengedit halaman layanan via **Elementor Pro**, dan mengelola pesan masuk calon klien secara mandiri.
