# Panduan & SOP Pengoperasian Website Garuda Karya Teknik

Selamat datang di dokumentasi resmi Standard Operating Procedure (SOP) dan panduan operasional pengelolaan website resmi PT Garuda Karya Teknik (garudakaryateknik.com).

Dokumen ini disusun untuk staf internal dalam mempublikasikan pembaruan proyek (Selected Works), artikel berita teknik, mengedit halaman layanan via Elementor Pro.
