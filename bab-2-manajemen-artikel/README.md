# Modul 2.1: SOP Pembuatan & Publikasi Portofolio Proyek dan Artikel

Website Garuda Karya Teknik menampilkan portofolio proyek terkurasi pada seksi "Selected Works" dan halaman "Projects Archive". Modul ini memandu staf dalam mempublikasikan proyek baru dengan struktur format baku yang konsisten.

---

## 2.1 Format Standar Portofolio Proyek GKT

Setiap publikasi proyek baru wajib mencantumkan 4 parameter utama:

```text
+-------------------------------------------------------------+
| CONTOH STRUKTUR PORTOFOLIO PROYEK GKT                       |
|                                                             |
| Judul Proyek : Coffee Shop Fit-Out                          |
| Lokasi       : Bojong Nangka, Bogor                         |
| SCOPE        : Fit-Out & Interior                           |
| AREA         : 150 sqm                                      |
| YEAR         : 2025 / 2026                                  |
|                                                             |
| [ Galeri Foto Dokumentasi Proyek / Before-After ]           |
| [ Narasi Penjelasan Solusi Rekayasa & Material ]            |
+-------------------------------------------------------------+
```

---

## 2.2 Prosedur Langkah Demi Langkah

### Langkah 1: Membuka Editor Post
1. Dari dashboard sebelah kiri, klik menu **Posts** -> klik **Tambah Baru (Add New Post)**.

---

### Langkah 2: Mengisi Judul dan Informasi Proyek
1. **Judul (Title)**: Masukkan nama proyek, contoh: `Modern Office Fit-Out & Interior`.
2. **Isi Deskripsi**:
   - Tuliskan ringkasan cakupan kerja (Scope), tantangan teknis, dan solusi konstruksi yang diterapkan oleh tim GKT.
   - Tambahkan sub-heading `## Scope of Work`, `## Engineering Challenges`, dan `## Key Results`.

---

### Langkah 3: Menentukan Gambar Sampul (Featured Image)
Foto sampul akan otomatis ditarik ke dalam kartu grid Selected Works di halaman beranda.

1. Pada bilah kanan layar (tab **Post**), gulir ke bawah ke seksi **Featured Image (Gambar Utama)**.
2. Klik **Set featured image**.
3. Unggah foto resolusi tinggi berorientasi horizontal (rasio 16:9 atau 4:3, resolusi rekomendasi 1200 x 800 px, ukuran file di bawah 250 KB).
4. Klik tombol **Set featured image**.

---

### Langkah 4: Memilih Kategori Layanan dan Tag
1. Pada bilah kanan (tab **Post**), buka seksi **Categories**.
2. Centang kategori bidang kerja yang sesuai:
   - `[x] Fit-Out & Interior`
   - `[x] Design & Build`
   - `[x] Build Construction`
   - `[x] MEP & Smart Building`
3. Masukkan Tag lokasi dan jenis bangunan (contoh: `bogor, coffee-shop, komersial, interior-kayu`).

---

### Langkah 5: Pengaturan Yoast SEO
1. Gulir ke bagian bawah editor ke kotak **Yoast SEO**:
   - **Focus Keyphrase**: Masukkan kata kunci utama (contoh: `kontraktor interior kafe bogor`).
   - **SEO Title**: Pastikan bar indikator berwarna hijau.
   - **Meta Description**: Tulis 1-2 kalimat ringkas (maks. 155 karakter) yang merangkum proyek ini untuk pencarian Google.

---

### Langkah 6: Publikasi
1. Klik tombol **Preview** untuk memeriksa tampilan di tab baru.
2. Jika sudah rapi, klik tombol biru **Publish** dua kali untuk menerbitkan ke publik.
3. Buka halaman `https://garudakaryateknik.com/projects-archive` untuk memastikan kartu proyek baru telah tampil di grid portofolio.
